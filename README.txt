# ZIA Natural Soap Collection App

## Run on Windows / VS Code

1. Install Python.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:

    py -m pip install -r requirements.txt

5. Then run:

    py app.py

6. Open:

    http://127.0.0.1:5000
